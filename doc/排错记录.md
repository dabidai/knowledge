## 二、知识图谱页面 500 错误

### 现象
点击"知识图谱" → 浏览器报 500，同时 Vite HMR WebSocket（`ws://localhost:3000/`）反复请求。

### 排查过程
1. 先以为是 JWT 过期 → 重登录后 403 变 500（确认 JWT 有效）
2. 怀疑 Neo4j 未启动 → `docker ps` 确认在跑
3. 怀疑密码不匹配 → 检查配置一致
4. 怀疑 `@AuthenticationPrincipal` 空指针 → 加了 department null 检查
5. 最后**临时注释掉 `@Cacheable`** → 500 消失，定位到缓存层

### 根因
`CacheConfig.buildWithTtl()` 从 JDK 默认配置创建 Redis 缓存配置（需 `Serializable`），未继承 Jackson JSON 序列化器。DTO 类未实现 `Serializable` → Redis 写入失败 → 异常穿透 `@Cacheable` 代理 → 500。

### 解决
`cacheCustomizer` 注入 `defaultCacheConfig` bean，per-cache TTL 配置从它派生，继承 Jackson 序列化器。

Commit: `0927120`

## 三、结构化浏览 / 导入历史 / 知识检索 页面 500

### 现象
分别报同样的 `{"code":500,"message":"服务器内部错误"}`。

### 原因
同「知识图谱」——各自端点上的 `@Cacheable` 注解全部受影响。

| 缓存名 | 端点 | 
|--------|------|
| `browseTree` | `GET /api/browse/tree` |
| `importTasks` | `GET /api/import/tasks` |
| `search` | `POST /api/search` |

### 解决
修复 `CacheConfig` 根因后，全部恢复。Commits: `9f7089e`, `8c31224`, `c3c03a7`, `0927120`

## 四、Health 白名单不完整

修复：部门创建与用户创建解耦 —— 部门始终幂等创建，admin 仅无用户时生成。

## 七、问答结果无文档下载链接

### 现象
AI 回答引用了文档内容，但看不到下载链接。

### 原因
前端把来源文档藏在 `el-collapse`（折叠面板）里，不点开就看不到。

### 解决
1. 来源面板默认展开，显示文件名 + "⬇ 下载原文"按钮
2. AI 回答中提到的文件名自动替换为可点击的 MinIO 下载链接
3. 文件不可用时显示"(文件暂不可下载)"

Commit: `0c8c829`

## 九、AI 可回答签阅人和事项信息

### 问题
之前 RAG 只搜 ES 文档正文。签阅记录和事项元数据在 PostgreSQL，AI 完全看不到。问"某文件的签约人是谁"回答不了。

### 解决
提问时同步查 PostgreSQL：
1. 问题关键词 → `items` 表标题 LIKE 匹配（最多 10 条）
2. 命中事项 → `opinions` 表查签阅记录
3. 格式化为结构化文本注入 RAG context
4. Python AI 提示词告知优先从结构化数据查找

Commit: `eb0b8ef`
